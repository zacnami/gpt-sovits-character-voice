# 推理、听评与手动WebUI

## 试听与比较

复用已有请求与条件一致的WAV；无记录时从当前官方配置建立明确基线。记录实际GPT/SoVITS权重、参考音频＋准确prompt、目标文本/语种、精度、采样、切分与seed。固定条件比较权重时保其余条件；探索参考或参数时明示改变，让结论只覆盖实际变量与样例。固定seed也不保证不同模型有相同随机轨迹。

按规模设置有限调用与资源，失败保异常及成功音频，定位后在授权和合理剩余成本内决定下一动作。交完整可播放WAV、对应请求和加载证据；手动任务只交可操作页面，不为预填验证代用户自动合成。

听评按日语、中文、长文本及实际需要的完整性、自然度、音色分别记录；未测试维度标未评估。用户主观比较按其真实条件及反馈保留，估计百分比不冒量化测量。短句接受不自动覆盖长段，技术PASS不代音质接受；用户改变结论时保历史及最新取舍。不同参考/推理条件带来的应用效果，与纯权重收益分开。

完成于本次要求的可播对照或手动页真实可用，质量结论有对应听证或明确待评；若用户停止某路线，保结果和现场，后续不把它继续列作默认恢复任务。

## 官方手动页与默认值

训练完成后默认使用本版本原生TTS入口或inference_webui脚本提供可操作推理页及链接，默认加载用户认可组合，否则本次选定权重；工作配置、weight.json和临时输出落独立可写根；原源码/模型/训练资料保持。核解释器、CWD与已有资产，loopback监听/share关闭。记录服务PID及创建身份，核HTTP、实际组件、参考可读与模型加载日志；页面字段或底稿只代表配置，加载证据才说明实际使用。

用户要求亲自用WebUI尝试时，准备模型、参考和默认参数，核页面与加载可用后即交其操作；此分支到交付结束，保现场等用户问题或新要求，不代点合成、主动自动试听/调参或附加强制听评清单、固定A/B前置。

交付明确列推理页地址和参考文件夹，与素材标注页区分；HTTP、实际模型加载及参考可读核通过才称页面交付成立。若服务确有阻碍，说明阻碍与尚缺项，不称完整交付；不自动合成或扩展训练。

有多组权重时用官方扫描目录或现有配置提供明确名称，保GPT/SoVITS成对来源并默认用户选定组合。持久启动默认、活页选择和服务实际加载是三种状态：只改下次默认时保持活服务；改活页用原生控件并等加载完成。切换、重启或让训练接管设备前保存未提交字段与当前选择，按精确服务身份安排，结束后恢复已保存输入与用户期望模型。关浏览标签不等服务退出。

用户满意的batch、语速等保项目偏好，通用Skill以当前版本和实际样例为依据；训练batch、推理chunk batch和审核页条数分别处理。改变参考、切分、bucket/parallel或推理batch时核其实际文本分组，不推断一个值对所有句子最好。对照保持原推理条件；应用探索的建议值留可选，不静默改用户现场。

## 已观察故障

| 观察 | 真实证据 | 必要行动与完成条件 |
|---|---|---|
| 网页不可用 | 端口、进程身份、启动日志 | 沿当前实例观察或修实际启动错误；HTTP与页面可用分别核，不因一次等待超时重复启动 |
| 缺文件/模块、配置类型错 | 首异常路径、CWD、解释器、原生配置解析值 | 优先复用本地资产和正确路径/类型，必要小修后验证；下载/升级范围按授权另定 |
| 模型选择不符 | 成对来源、活页字段、加载日志 | 用原生选择并等完成，保可恢复默认/输入，核实际新加载而非只看名称 |
| 生成或训练失败 | 原始trace、实际调用/消费及退出、已有产物 | 保已成功部分；根据根因证据和预算修必要范围，未知失败不自动变更数值 |
| 末音短促、气音或音色差 | 实际问题WAV与text/ref/推理条件、用户具体听感 | 先区分本句自然表演与缺词/邻声；核相关生成或后处理事实，原因未知时保假说，选择有判据的有限后续 |

重复试验缺乏收益时，说明什么已被证伪、什么仍未知及下一候选的判断价值；在既有授权范围内选择下一项有判据的行动；改变范围或恢复用户已停止的路线时再确认。完整模型保存、音频时长和ASR一致分别是技术线索，不能据此签声音改善。
