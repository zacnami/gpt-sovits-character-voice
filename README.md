# GPT-SoVITS 角色语音训练全流程 Skill

中文 | [English](README.en.md)

让 Agent 使用官方 GPT-SoVITS，完成从原始语音素材到角色语音模型的完整训练流程。覆盖素材切分、BGM 处理与降噪、语音转写与校对、数据整理、特征提取、GPT / SoVITS 训练，以及训练后的推理试听和 WebUI 交付。

默认使用所选官方版本的预训练权重和训练参数；已有用户确认的训练配方时沿用该配方，需要调整时说明原因和差异。

工作流不限定素材语言，具体支持的语言与训练方式取决于所用 GPT-SoVITS 版本。维护者目前训练出的两份权重均使用日语素材；其他语言的效果需要实际训练与试听验证。

## 完整流程

1. **准备环境与素材。** 检查官方 GPT-SoVITS 版本、运行环境、预训练权重及目标角色的原音和台词，保留原始资料。
2. **切分语音。** 整理长音频或已有片段，检查切分边界、首尾发音、相邻对白和其他说话人的声音，为素材保留稳定编号。
3. **处理 BGM 与噪声。** 用户先手动挑出带 BGM 或需要降噪的语音，将对应编号发给 Agent。Agent 根据编号定位素材并执行相应处理，保留原音与处理版的对应关系，再交用户试听确认。
4. **转写与校对。** 使用已有台词或 ASR 草稿核对音文，在官方素材审核页检查和修订，确认本次采用的素材版本。
5. **整理训练数据并提取特征。** 准备所用版本要求的音频格式和标注文件，提取或同步文本、音频及语义等所需特征，核对训练实际读取的数据。
6. **训练 GPT 与 SoVITS。** 默认基于官方预训练权重和参数运行，记录配置、进度与保存结果；出现故障时定位原因，根据已有产物安排恢复。
7. **交付模型与推理入口。** 整理可辨认的权重和参考音频，提供官方推理 WebUI，支持手动试听及已授权的对照生成。

BGM 与降噪环节需要用户提供待处理语音的编号，不会自动识别并处理所有素材。素材采用和最终声音效果由用户确认，技术检查用于核对数据、训练和模型加载是否正常。

## 安装与使用

将本仓库下载或克隆为名为 `gpt-sovits-character-voice` 的目录，放入所用助手的 Skill 目录。保留 `SKILL.md`、`references/` 和 `agents/` 的相对结构，并按助手的说明加载 Skill。

调用 `$gpt-sovits-character-voice`，说明素材位置和本次目标即可。

指定素材处理示例：

```text
我手动检查了这批语音，编号 0012、0037、0085 有 BGM。
请处理这些编号对应的语音，保留原音，处理后交给我试听。
```

可以从已有项目的任意阶段接续，也可以只完成素材处理、训练或推理中的指定阶段。执行范围以当前任务授权为准。

## 运行条件与范围

本仓库提供 Agent 工作流说明。执行任务需要另行准备官方 GPT-SoVITS、对应运行环境、模型及所需的音频处理工具；仓库不附带程序、权重或训练素材。

参数、文件格式与启动入口以实际使用的 GPT-SoVITS 版本为准。素材质量、语言、模型版本和训练条件可能影响最终效果，训练完成不代表已经通过听觉验收。游戏资源解包需使用对应工具；请仅使用有权处理的声音、文本和模型。
